# Zenodo dataset deposit metadata

**Resource type:** Dataset

**Title:** HIS Synthetic Benchmark V1.3: Frozen Reproducibility Subset for
Heterogeneous Data Cleaning and Standardization

**Version:** 1.0.0

**Creators:** Haoyi Wang; MinPo Jung

**Description:** This deposit contains only synthetic hospital-information-
system benchmark tables, canonical references, source-valid tables, frozen
corruption conditions, rule files, and integrity manifests used to reproduce
the reported internal experiments. It contains no MIMIC-IV data, no real
patient records, and no patient-level derivatives of restricted clinical data.
The accompanying public software repository contains the frozen cleaning
implementation, evaluator, configuration-driven wrappers, aggregate evidence,
and MIMIC-compatible code that requires independently authorized data access.

**Keywords:** hospital information system; data cleaning; synthetic data;
reproducibility; data quality; MIMIC-IV
